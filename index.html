AppleRaider - Tomb Raider for macOS users

AppleRaider helps you to make run Core Design's Tomb Raiders, on your macOS enviroment

WORK IN PROGRESS!! THE FAN PAGE ISN'T COMPLETE YET

TRX

TRX is an open source and cross platform engine for Tomb Raider I-II-III, and macOS is supported (both Intel and Apple Silicon)

Supported Games: TR1, TR2 and TR3 (including golds)

Parallels Desktop

Parallels Desktop is a paid software for macOS that lets you create a Windows 11 VM and have accelerated graphics.

Supported Games: All

VMWare Fusion

The free alternative to Parallels Desktop, but more limited.

Supported Games: All
